### Chaîne C — la preuve que la transcription n'avait pas vue : le dessin est *calculable*

La transcription proposait une « corroboration » approximative
($\theta_m \approx 10°$). **En fait le tracé est exact.** Le sujet pose
$\sin\theta \simeq \theta$ ; le potentiel harmonique correspondant est
$E_{pp} = \frac12\,mg\frac{\ell}{2}\theta^2$. Avec les données
**imprimées** $m = 0{,}203$ kg et $\ell = 1{,}5$ m, et $g = 9{,}8$
N·kg⁻¹ :

$$E_{pp}(\theta_m) = \tfrac12 \times 0{,}203 \times 9{,}8 \times 0{,}75 \times (10°)^2
= \tfrac12 \times 1{,}49205 \times 0{,}0304617 = \mathbf{22{,}725\ \text{mJ}}$$

**contre 22,728 mJ mesurés sur le tracé vectoriel — 0,013 % d'écart,
soit 3 microjoules.** Le dessinateur a porté la formule, avec
$\theta_m = 10{,}00°$ rond et $g = 9{,}8$. *(La forme exacte
$mg\frac{\ell}{2}(1-\cos\theta_m)$ donnerait 22,670 mJ — l'accord est
donc avec la version **harmonisée**, celle que l'énoncé impose. C'est
une signature, pas une coïncidence.)*

**Et elle boucle sur la question 2-2** : $\dot\theta = \theta_m\omega_0\sqrt{5}/3$
avec $\omega_0 = \sqrt{3g/2\ell} = \sqrt{9{,}8} = 3{,}1305$ rad·s⁻¹ donne
$|\dot\theta| = 0{,}4072$ rad·s⁻¹ — **exactement** la valeur que rend la
lecture graphique ($\sqrt{6E_c/m\ell^2}$ avec $E_c = 12{,}63$ mJ :
0,4073). Trois chemins, trois fois 0,41.

### ⚠️ F1 — DÉFAUT IMPRIMÉ : l'amortissement de la figure 4 est incompatible avec les 208,4 Ω du circuit

**Le fait, mesuré.** La figure 4 donne $u_C(t)$ pour un circuit
$C = 0{,}2\ \mu$F, $R' = 200\ \Omega$, bobine $(L, r)$ avec
$r = 8{,}4\ \Omega$ (établi par l'énoncé lui-même, § 1.2, contrôle 2) —
soit une résistance totale de **208,4 Ω**. Sur le tracé vectoriel de
l'original, les extrema successifs valent
$4{,}474 \rightarrow -4{,}056 \rightarrow 3{,}830 \rightarrow -3{,}461 \rightarrow 3{,}280$ V :
le rapport d'une pseudo-période à la suivante est **0,855** (0,856 / 0,853 / 0,856 — remarquablement
constant).

Or, pour un $RLC$ série,
$u_C \propto e^{-\frac{R_{tot}}{2L}t}$, donc le rapport par période
vaut $e^{-R_{tot}T/2L}$. Avec $L = 0{,}2$ H et
$T = 2\pi/5$ ms, la valeur imprimée $R_{tot} = 208{,}4\ \Omega$ prédit
un rapport de **0,520**. Le rapport dessiné, 0,855, correspond à

$$R_{tot}(\text{dessin}) = -\frac{2L\ln 0{,}855}{T} = \mathbf{49{,}9\ \Omega}$$

**soit un facteur 4,2 sur la résistance.** *(Chaîne : géométrie
vectorielle de l'original ; les mêmes extrema relevés au pixel sur le
bitmap français donnent 4,44 pour le premier — même conclusion.)*
