# fonction-logarithme — revue de correction (2026-09-11)

Vague-1 (bac-fidelity-critic + pedagogy-critic) sur `content/maths/fonction-logarithme/`.

**Le cœur mathématique est intègre.** Recalcul indépendant, croisé avec le balayage
du critique fidélité : équation fonctionnelle et propriétés (produit par égalité des
dérivées, inverse/quotient/puissance par récurrence, racine), dérivée `(ln u)'=u'/u`
avec la garde `u>0`, les limites de référence (`ln x`→±∞, `ln x/x`→0, `x ln x`→0) et
la preuve par `φ(t)=t−1−ln t`, la bijection/TVI, `e`, la tangente `y=x−1` liée à la
concavité (`ln''=−1/x²<0`), les trois exemples R6 (domaine d'abord, `x²−3x−2=0` Δ=17,
racine `(3−√17)/2` rejetée ; inéquation `S=]½,4[`), le log décimal, **et les deux
exercices-sommets** (r-bac 2019 : `f'=(x−1+ln x)/x`, inflexion `I(e²,e²+½)`,
`f(x)−x=½(ln x−1)²`, IPP `∫₁^e(ln x)²=e−2`, aire `e−5/2`, suite → `e` ; r-variation :
`f'=(x−2ln x+2)/x` via `n(2)=4−2ln2>0`, aire `2e−5`, suite décroissante → `e`) — **tout
se reproduit**. Aucun faux universel ; tous les `chapitre N` intra-leçon de `lesson.md`
sont corrects. Les défauts sont dans la couche banque, la couverture cadre, et un amas
d'erreurs de citation/étiquetage atteignant le texte rendu.
