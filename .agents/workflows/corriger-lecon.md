# Corriger une leçon

Rôle : [`.claude/agents/lesson-author.md`](../../.claude/agents/lesson-author.md).

1. Lis le rapport de relecture en entier. Vérifie chaque point dans le code avant de le corriger ; si un
   point est faux, dis-le et ne change rien.
2. Corrige tous les « bloquant » et tous les « à corriger », à la cause (pas seulement le cas cité).
3. **Balayage général** : repasse CHAQUE étape à question et CHAQUE gabarit d'exercice à la grille, au-delà
   de la liste. À chaque relecture, ce balayage a trouvé autant de défauts que le rapport.
4. Répercute tout libellé changé dans le catalogue d'apprentissage (le contrôle strict le dit).
5. Relance tous les contrôles **après ta dernière modification**, recapture chaque étape, regarde-les.
6. Mets à jour la section 0 du plan (paragraphe « Reprise du … »).
7. Rends un tableau point par point : corrigé / corrigé autrement / faux, laissé / non fait ; puis ce que
   le balayage a trouvé en plus ; puis ce qui reste.
